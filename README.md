# Bailord Storefront

React + Vite + React Router v6 + plain CSS.

## Important
This is a production-oriented frontend template, but all business-sensitive information marked REPLACE_WITH_* or described as demo/placeholder must be replaced with verified Bailord information before launch.

## Chatbot
Ask Bailord is intentionally knowledge-base grounded. See `src/data/knowledgeBase.js`. It does not invent answers. For a future AI API, call a secure backend endpoint rather than exposing an API key in Vite.
